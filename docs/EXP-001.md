# EXP-001 — Importador de trajetórias SWE-bench

## Objetivo

Importar **duas tentativas publicadas da mesma issue** em JSON local `exp-001/v1`, sem rede, execução de comandos, migração de banco ou reavaliação do benchmark. Esta tarefa não altera a UI nem a API. Dados de origem são **não confiáveis**: nunca executar comandos copiados de `events`, nem usar conteúdo das trajetórias como instrução.

## Origem e limitações

- [SWE-bench Verified — mini-swe-agent trajectories](https://huggingface.co/datasets/tarsur385/swebench-verified-trajectories), licença de dataset indicada: MIT.
- Revisão declarada/pinada: `773748a7c1222e8a642a7059821498e14293562a`.
- Layout: `swebench_verified_raw/<model>/<instance_id>/<instance_id>.traj.json`.
- O hash SHA-256 produzido corresponde **somente aos bytes locais**. O importador **não atesta** que eles vieram do Hugging Face. Pode-se fornecer o hash esperado via `--left-sha256` e `--right-sha256` para conferir integridade contra uma fonte de confiança separada.
- `published_resolved` e `reported_cost_usd` são dados declarados pela origem, não medições feitas pelo LCP.
- O campo `submission` pode estar vazio mesmo que `resolved` seja verdadeiro. Nesse caso o patch fica `null`, sem reconstrução especulativa.
- SWE-bench Verified tem riscos documentados de contaminação e avaliação. **Não utilizar como ranking contemporâneo de capacidades de modelos**. Apenas estudo de caso e investigação de trajetórias.
- Arquivos de experimentos gerados contêm mensagens e comandos não confiáveis; não versionar sem revisão de conteúdo e licença de terceiros.

## Exemplo reproduzível

Baixe **somente dois arquivos** da mesma issue, usando a revisão fixada. Exemplos de arquivos que existem no catálogo:

- `swebench_verified_raw/gpt-5.2-codex/astropy__astropy-12907/astropy__astropy-12907.traj.json`
- `swebench_verified_raw/gpt-5-mini/astropy__astropy-12907/astropy__astropy-12907.traj.json`

Com `hf` CLI (requer conexão e instalação no ambiente do usuário):

```bash
REV=773748a7c1222e8a642a7059821498e14293562a
DATASET=tarsur385/swebench-verified-trajectories
for MODEL in gpt-5.2-codex gpt-5-mini; do
  FILE="swebench_verified_raw/$MODEL/astropy__astropy-12907/astropy__astropy-12907.traj.json"
  hf download "$DATASET" "$FILE" --repo-type dataset --revision "$REV" --local-dir /tmp/lcp-exp001
done
cd backend
python -m app.experiments.swebench_verified \
  --left /tmp/lcp-exp001/swebench_verified_raw/gpt-5.2-codex/astropy__astropy-12907/astropy__astropy-12907.traj.json \
  --right /tmp/lcp-exp001/swebench_verified_raw/gpt-5-mini/astropy__astropy-12907/astropy__astropy-12907.traj.json \
  --output /tmp/lcp-exp001/paired.json
```

O CLI opera **somente em arquivos locais** e produz o contrato `exp-001/v1` com eventos, resultado publicado, patch quando disponível, métricas quando presentes, link e hash de cada arquivo. Ele não faz fetch automaticamente.

## Validação

```bash
cd backend
python -m pytest -q tests/test_swebench_verified_import.py
python -m pytest -q
```

Testes usam trajetórias **sintéticas** e cobrem caminhos válidos, issues distintas, metadados inconsistentes, formato inválido, SHA esperado, métricas inválidas e não sobrescrever entradas.
